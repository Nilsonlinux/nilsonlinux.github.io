Como instalar 3 formas

1

Gerar a ISO (máquina Arch)

O script instala o archiso, regera o perfil, aplica o branding NLinux, transforma o boot (systemd-boot + GRUB + syslinux) e roda o mkarchiso. Compila a AUR no chroot — build lento, precisa de internet.

bash
# clone e gere a ISO
git clone https://github.com/Nilsonlinux/nlinux.git
cd nlinux
./build-iso.sh
# grave no pendrive
sudo dd if=iso/out/nlinux-*-x86_64.iso of=/dev/sdX bs=4M status=progress conv=fsync
2

Instalar pelo live (instalador web)

Boote a ISO, clique em Instalar NLinux no desktop — o Firefox abre em kiosk apontando para http://127.0.0.1:8765. Siga os 10 passos do assistente e acompanhe a barra de progresso. Não há instalador TUI.

login do live
usuário: nlinux
senha:   nlinux
host:    nlinux · fuso America/Sao_Paulo
3

Sem ISO: instalador direto

Monte o projeto na máquina alvo e execute como root. Pré-checagens exigem root, UEFI e internet (avisa sem rede). Para não-interativo, exporte as variáveis antes.

bash
sudo ./install.sh

# ou não-interativo:
sudo env INSTALL_USER=felipe INSTALL_USER_PASS=senha123 \
  ROOT_PASS=senha123 INSTALL_DISK=/dev/nvme0n1 \
  FS_TYPE=btrfs USE_LUKS=1 GPU=amd ./install.sh
