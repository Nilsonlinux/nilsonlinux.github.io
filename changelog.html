Como ler

Este changelog lista as versões do NLinux publicadas como GitHub Releases, começando pelas mais recentes. Cada entrada mostra as mudanças da ISO e os arquivos anexados à release.

NLinux é rolling. Uma ISO é uma fotografia: os repositórios do Arch continuam andando depois dela. Por isso duas pessoas que instalaram a mesma ISO em dias diferentes podem ter pacotes diferentes. Para o dia a dia, atualize com sudo pacman -Syu em vez de reinstalar.

As versões são carregadas das GitHub Releases do nlinux-iso-build. Para adicionar uma entrada, publique uma release com a tag da versão, notas das mudanças e os arquivos da ISO e do checksum. A página consulta as releases automaticamente; não é preciso editar o HTML.
